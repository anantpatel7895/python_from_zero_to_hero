# Python Decorators: Beginner to Advanced

**Goal:** by the end of these notebooks you can read, write and design decorators with confidence.

## Roadmap

| Level | Topic | You will learn |
|---|---|---|
| 0 | Foundations | Functions are objects, inner functions, closures |
| 1 | Your first decorator | Wrapping a function by hand, then with `@` |
| 2 | General-purpose wrappers | `*args`, `**kwargs`, return values |
| 3 | `functools.wraps` | Keep the original name and docstring |
| 4 | Real-world decorators | Timer, logger, call counter |
| 5 | Decorators with arguments | `@repeat(3)`: decorator factories |
| 6 | Stacking decorators | What order they run in |
| 7 | Class-based and stateful decorators | `__call__`, keeping state |
| 8 | Built-in decorators | `@property`, `@staticmethod`, `@classmethod`, `@lru_cache` |
| 9 | Advanced patterns | Optional arguments, retry, registry, validation, class decorators |
| 10 | Practice | Exercises with solutions |

**How to use it:** run each cell with `Shift + Enter`. Predict the output **before** you run a cell, then check if you were right.
